Task 1 · Context

Background Information

Starting this fall, Beast Classroom will offer two versions of each unit: Core and Go Deeper.

Core A Core unit follows the standard curriculum you're already familiar with.
Go Deeper A Go Deeper unit marks 4 lessons as skippable and adds 4 enrichment lessons for students who are ready for more challenges.

For every unit you teach, you can choose a version for each class. Today, we'd like to see if our interface is intuitive for you to easily switch between these two versions.

Your Task

Find Class 3B's curriculum, find Unit 2, and switch "Standard" to "Go Deeper" for your students.
